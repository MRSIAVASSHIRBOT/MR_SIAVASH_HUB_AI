روش استفاده حرفه‌ای

  1. اول هدف و سوژه را دقیق کن؛ صفات تزئینی جای اطلاعات واقعی را نمی‌گیرند.
  2. ترکیب‌بندی، زاویه دوربین و نور را جداگانه تعیین کن.
  3. عناصر ضروری و موارد ممنوع را روشن بنویس.
  4. نسخه‌های مختلف را با تغییر یک متغیر مقایسه کن.
  5. پرامپت را متناسب با مستندات مدل مقصد تنظیم کن؛ پارامترهای مدل‌ها یکسان نیستند.
  6. خروجی واقعی را بررسی کن و بر اساس خطاهای دیده‌شده اصلاح انجام بده.
محدودیت نسخه فعلی: بدون اتصال API یا مدل محلی، امکان تولید تصویر/ویدئو، ترجمه ماشینی واقعی، جست‌وجوی وب، تحلیل خودکار تصویر ورودی یا بهینه‌سازی مبتنی بر پاسخ مدل وجود ندارد. ابزار در عوض پرامپت ساختاریافته می‌سازد و مدیریت می‌کند.
